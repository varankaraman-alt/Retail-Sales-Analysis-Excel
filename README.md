# Retail Sales Analysis Dashboard | Excel

## Project Overview
This project focuses on analyzing retail sales data using Microsoft Excel. The goal is to understand sales performance, profitability, customer satisfaction, and business trends through an interactive dashboard.

## Dataset
- Total Records: 2,000
- Business Domain: Retail Sales
- Data Includes: Orders, products, regions, customer types, payment modes, discounts, and customer ratings.

## Workbook Structure
1. **Raw Data:** Original retail sales dataset.
2. **Data Cleaning and Calculation:** Data preparation and calculated columns.
3. **Pivot Table and Chart:** Data summarization and analysis.
4. **Dashboard:** Interactive sales dashboard.
5. **Insight and Conclusion:** Key findings and business recommendations.

## Excel Skills Used
- Data Cleaning
- Excel Tables
- IF and Nested IF
- SUM, SUMIF, COUNTIF
- Calculated Columns
- Pivot Tables
- Pivot Charts
- Slicers
- Dashboard Design
- Business Insights

## Key Performance Indicators (KPIs)
- Total Net Revenue
- Total Profit
- Profit Margin
- Total Orders
- Customer Satisfaction

## Key Business Insights
- Analyzed monthly sales performance.
- Evaluated regional and category-wise revenue.
- Identified profitable products.
- Analyzed customer satisfaction.
- Studied the impact of discounts on profitability.

## Business Recommendations
- Control excessive discounts to protect profit margins.
- Improve customer experience.
- Focus on profitable products and regions.
- Encourage repeat purchases through customer retention strategies.

## Tools Used
Microsoft Excel

## Project Objective
To demonstrate practical Excel and data analysis skills by converting raw retail sales data into meaningful business insights.
